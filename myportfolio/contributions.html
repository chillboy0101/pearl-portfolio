Linux Kernel Contribution

In August 2026 I fixed a hardware bug in the Linux kernel's sound driver. The patch was reviewed and applied by the Linux sound subsystem maintainer.

Accepted upstream

ALSA: Mute LED fix for HP Laptop 15-dy0xxx

The mute LED on this HP laptop (Realtek ALC236 codec) never lit because the model had no entry in the driver's quirk table. I traced the LED to a codec register (COEF 0x07, bit 0) using hda-verb, verified it on the hardware, and submitted a one-line fix that reuses an existing driver routine.

C Linux kernel ALSA Hardware debugging
Read the patch thread 
Subject: [PATCH] ALSA: hda/realtek: Enable mute LED on HP Laptop 15-dy0xxx

The LED is controlled by COEF index 0x07, bit 0.
This was verified on the hardware with hda-verb.

Tested on an HP Laptop 15-dy0xxx
(SKU 7FU54UA#ABA, board 864F, BIOS F.40).

Signed-off-by: Carl Quist
Applied now.
Takashi Iwai, Linux sound subsystem maintainer
