Save each recording here as an MP4 (H.264) with these exact names, and it will play on the
site with no other change:

| Edinam Hospital | `edinam-demo.mp4` |

Until a file is added, pressing play shows `demo_video_coming_soon/`.
Keep each video short (30–90 seconds) and under about 15 MB so it loads quickly.
