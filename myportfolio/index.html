linux_kernel / alsa / hda-realtek

A fix in the Linux kernel

The mute LED on HP Laptop 15-dy0xxx machines (Realtek ALC236) never lit because the model had no entry in the sound driver's quirk table. I traced the LED to codec register COEF 0x07, bit 0, with hda-verb, verified it on the hardware, and submitted a one-line fix. Takashi Iwai, the Linux sound subsystem maintainer, applied it in August 2026.

Read the patch ↗ Maintainer's reply ↗ 
Subject: [PATCH] ALSA: hda/realtek: Enable mute LED on HP Laptop 15-dy0xxx

The LED is controlled by COEF index 0x07, bit 0.
This was verified on the hardware with hda-verb.

Tested on an HP Laptop 15-dy0xxx
(SKU 7FU54UA#ABA, board 864F, BIOS F.40).

Signed-off-by: Carl Quist
Applied now.
Takashi Iwai, Linux sound subsystem maintainer
