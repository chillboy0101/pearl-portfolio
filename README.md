# Pearl Amissah - Professional Portfolio

A modern, responsive portfolio website showcasing Pearl Amissah's creative work and professional services.

## 🎨 Features

- **Responsive Design**: Optimized for all devices
- **Modern UI**: Clean, professional design with smooth animations
- **Portfolio Showcase**: Display of creative projects and work
- **Services Overview**: Comprehensive list of professional services
- **Contact Form**: Easy way for clients to get in touch
- **Social Media Integration**: Links to professional social profiles

## 📁 Pages

- **Home** (`index.html`) - Landing page with introduction
- **Services** (`services.html`) - Professional services offered
- **Portfolio** (`portfolio.html`) - Work showcase and projects
- **Contact** (`contact.html`) - Contact form and information

## Carl Christian Quist portfolio

[`myportfolio/`](myportfolio/) is Carl Christian Quist's portfolio (IT Officer | Software Developer),
served at `/myportfolio/`. It is a single page in the style of GitHub Universe: a pale grey-green
grid of bordered cells, Mona Sans and JetBrains Mono type, code-path section titles, a live Accra
clock, a code-character cursor trail, pixel mosaics and black-and-white screenshots that turn to
colour on hover. All motion is switched off for visitors who prefer reduced motion.

The hero holds Super Carl, an endless platformer drawn on a canvas (`myportfolio/assets/js/game.js`):
arrow keys or A/D to move, Space to double jump, on-screen buttons on phones, and a high score kept
in the browser.

Styles are in `myportfolio/assets/css/universe.css` and behaviour in `myportfolio/assets/js/universe.js`.
The old `services.html`, `portfolio.html`, `contributions.html` and `contact.html` URLs redirect to
the matching section of `index.html`.
