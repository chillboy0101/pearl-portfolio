# Pearl Amissah - Professional Portfolio

A modern, responsive portfolio website showcasing Pearl Amissah's creative work and professional services.

## 🎨 Features

- **Responsive Design**: Optimized for all devices
- **Modern UI**: Clean, professional design with smooth animations
- **Portfolio Showcase**: Display of creative projects and work
- **Services Overview**: Comprehensive list of professional services
- **Contact Form**: Easy way for clients to get in touch
- **Social Media Integration**: Links to professional social profiles

## 📁 Pages

- **Home** (`index.html`) - Landing page with introduction
- **Services** (`services.html`) - Professional services offered
- **Portfolio** (`portfolio.html`) - Work showcase and projects
- **Contact** (`contact.html`) - Contact form and information

## 🚀 Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (minimal)
- Font Awesome Icons
- Google Fonts (Playfair Display & Montserrat)
